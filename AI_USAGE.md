How I Used AI

I used Copilot in some parts of this project, mainly when I was stuck on code that I couldn't figure out or when my code repeatedly failed after typing it. Copilot helped me understand the different mistakes I was making in my code. Earlier in the project my code wasn't working because I didn't have Python installed on my computer.

Challenges and Mistakes

Not everything went smoothly. The original program displayed an error when I entered letters instead of numbers. After testing it, I used Copilot to help add error handling. Another mistake I made was committing an empty file because I had not saved it. I corrected this by saving the file, staging it again and checking the changes before committing.

What I Would Do Differently

Next time I would slow down when typing commands in the terminal to avoid making too many mistakes. I would also check my assignment requirements throughout the project and make sure my files are saved before committing them. Overall AI helped me when I couldn't figure out certain errors and helped me understand how testing and GitHub work together.
