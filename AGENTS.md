Personal Budget Tracker

Project Purpose

This Python application helps users calculate their total expenses and remaining balance based on their income to help keep them on track financially.

Setup and Usage

 Install Python.
 Install pytest using python -m pip install pytest.
 Run the program using python main.py.

Testing

 Run python -m pytest to check all tests.
 Add tests when adding new features.
 Make sure all tests pass before committing changes.

Project Files

 main.py contains the application code.
 test_main.py contains the unit tests.
 README.md explains how to install and use the program.
.github/workflows/ci.yml contains the automated testing workflow.

Coding Guidelines

 Keep the code simple and easy to understand.
 Use clear variable and function names.
 Use lowercase names with underscores for Python functions and variables.
 Use consistent indentation.
 Handle invalid user input.
 Write short and clear commit messages that describe the changes.

Protected Files

 Do not change the GitHub Actions workflow or .gitignore without permission.
 Do not remove existing tests or change the purpose of the application without permission.
